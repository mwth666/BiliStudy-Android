# B站学习陪伴 · 手机版（Android）

手机上刷 B 站网课时的陪伴助手：**自动记录每天看了多久，按内容进度计时，倍速算倍速**，还能和电脑上的浏览器插件合并数据。

- 自动读 B 站播放会话的**播放位置 / 时长 / 倍速**，不用手动点开始
- 3 倍速播 1 分钟 = 记 3 分钟内容进度，跟电脑插件完全同一口径
- 暂停、切后台、拖动进度条都不计时，防止"挂着刷时长"
- 今日 / 本周 / 本月时长、连续打卡、课程进度
- 常驻通知显示今日时长，不用打开 App 也能看到
- 支持与浏览器插件**手动合并数据**（无需账号、不联网、不上传）

安装包：`BiliStudy.apk`（约 37 KB）

---

## 一、安装与授权（重要）

1. 把 `BiliStudy.apk` 传到手机（微信/QQ 文件传输助手、数据线均可），点开安装。
2. 打开 App，会看到两个必做的授权：

### ① 开启「通知读取权」（必须，否则完全不记）

App 里点 **「去开启通知读取权」**，在系统列表里找到 **「B站学习陪伴 · 播放监听」**，把开关打开。

> 为什么需要这个权限：Android 只允许通过媒体通知读取 B 站的播放位置、时长和倍速。
> 本 App **只读 B 站（tv.danmaku.bili 等）的媒体播放通知**，不读微信/短信/其他任何应用的内容，不联网、不上传。

找不到入口时：

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi | 设置 → 应用设置 → 应用管理 → 权限 → 通知使用权 |
| 华为 / 荣耀 | 设置 → 应用 → 权限 → 通知读取 |
| OPPO / 一加 | 设置 → 应用管理 → 权限管理 → 通知使用权 |
| vivo | 设置 → 应用与权限 → 权限管理 → 通知使用权 |

### ② 允许发送通知（Android 13+）

首次启动会问「允许发送通知」，点允许，否则常驻通知看不到。

---

## 二、平时怎么用

装好授权后**什么都不用做**：在 B 站 App 里正常看网课即可，App 会在后台自动统计。

打开 App 可以看到：

- **今日观看 / 本周 / 本月**：按内容进度累计
- **🔥 连续打卡天数**：当天累计满 60 秒算打卡
- **课程进度**：按视频标题聚合，显示每门课看了几节/完成几节
- **常驻通知**：下拉通知栏就能看到「今日 1小时23分 · 播放中 3x」

### 计时规则（和电脑插件一致）

| 情况 | 是否计时 |
|---|---|
| 1 倍速播放 | 播 1 分钟记 1 分钟 |
| 3 倍速播放 | 播 1 分钟记 3 分钟 |
| 暂停 / 缓冲 | 不计时 |
| 拖动进度条 | 该段丢弃，不算进度 |
| 切到别的 App / 锁屏 | B 站媒体会话还在播就继续记（因为是真在放内容） |

## 三、和电脑插件合并数据（你选的功能）

两边都是纯本地存储、**不用账号、不上传**，靠手动导出/导入 JSON 合并：

### 手机 → 电脑

1. 手机 App 里点 **「导出给电脑」**，数据会复制到剪贴板。
2. 粘贴到微信文件传输助手发到电脑，另存为 `bili-study.json`。
3. 电脑插件：打开「查看完整统计 →」→ **「导入手机数据」** → 选这个文件。

### 电脑 → 手机

1. 电脑插件：打开「查看完整统计 →」→ **「导出 JSON」**，得到 `bili-study-日期.json`。
2. 把这个文件传到手机。
3. 手机 App 里点 **「导入电脑数据」** → 选该文件。

**合并规则**：

- 同一天的时长**相加**（比如电脑记 120 秒 + 手机记 45 秒 = 165 秒）
- 课程记录取并集
- 用内容指纹去重：**同一份文件重复导入不会让时长翻倍**

---

## 四、数据存在哪

全部存在手机 App 私有目录的 SharedPreferences，卸载即彻底删除。App 不联网、不上传、不用登录。

---

## 五、注意事项 / 已知限制

- **只支持 B 站官方客户端**（tv.danmaku.bili 及常见渠道版/国际版/HD）。第三方客户端可能不发标准媒体通知，就无法统计。
- **通知读取权可能被系统自动收回**：如果发现某天突然不记了，回 App 看状态栏是否变黄，重新开一次权限即可（跟无障碍被关是同类问题，国产 ROM 常见）。
- **标题即课程名**：手机上拿不到 B 站的 bvid，所以用视频标题作为课程标识，同名视频会算到同一门课。

## 六、构建源码（离线，无需 Android Studio）

工程在 `E:\BiliStudy`，用 SDK 自带工具链手动打包：

```bash
bash build.sh     # Git Bash 下执行，产出 BiliStudy.apk
```

需要：`E:\Android\jbr`（JDK21）、`%LOCALAPPDATA%\Android\Sdk\build-tools\35.0.1`、platform android-35。
不联网、不需要 Gradle。

源码结构：

```
app/src/main/
├── AndroidManifest.xml
├── java/com/bilistudy/app/
│   ├── MainActivity.java            看板 + 授权向导 + 导入导出
│   ├── BiliNotificationListener.java 通知监听（取 B 站媒体会话）
│   ├── SessionBridge.java           会话识别 / 状态采样
│   ├── TrackService.java            常驻采样 + 计时核心
│   ├── StatsStore.java              本地存储 / 统计 / 合并
│   └── BootReceiver.java            开机自启
└── res/                             界面资源
```
